# Primăria Orașului Vânju Mare - Website Oficial Modernizat

Platformă web modernă, rapidă și complet accesibilă pentru **Primăria Orașului Vânju Mare**, Județul Mehedinți.

## 🏛️ Caracteristici Principale
- **Arhitectură modernă:** Construit cu React 19, Vite 6 și Tailwind CSS v4.
- **Tipografie & Identitate:** Font serif elegant (Lora), stema oficială și culorile heraldice ale orașului.
- **Monitorul Oficial Local:** Acces direct și structurat la hotărâri, dispoziții, registre și documente publice.
- **Transparență decizională:** Piloni de dezvoltare, conducere executivă, organigramă și contact oficial.
- **Integrare Ghișeul.ro:** Widget flotant dedicat pentru plăți online ale taxelor și impozitelor locale.
- **Asistent Virtual AI:** Modul de chat inteligent pentru asistența cetățenilor și răspunsuri rapide la întrebări frecvente.

## 🚀 Instalare și Rulare Locală

```bash
# Navigare în directorul frontend
cd frontend

# Instalare dependențe
npm install

# Rulare server de dezvoltare
npm run dev

# Compilare pentru producție
npm run build
```

## 📂 Structura Proiectului
- `frontend/src/components/` - Componente UI modulare (Monitorul Oficial, Chatbot, Ghișeul.ro, etc.)
- `frontend/src/mediaData.js` - Resurse media oficiale și configurații galerii
- `frontend/public/imagini/` - Active vizuale autentice (stema orașului, fotografii sediu, afișe oficiale)
- `PLAN_REFACERE_PRIMARIA_VINJU_MARE.md` - Documentație de planificare și paritate arhitecturală
